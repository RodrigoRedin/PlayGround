# PlayGround

## Dragon Ball: Fusion World

An original, unofficial fan-made single-player card battler. Charge energy, play
Battle Cards, combo for extra power, block with defenders, and awaken your Leader
to take on six opponents.

- Six-stage campaign: Yamcha, Frieza, Android 18, Cell, Majin Buu and Beerus.
- Four playable Leaders: Goku, Vegeta, Piccolo and Frieza (unlocked after stage 3).
- Leadership abilities, blockers, rush, double strike, combos, awakening and deck-out losses.
- Progress, stars, settings and leader choice save automatically in `localStorage`.
- Keyboard, mouse and touch controls; responsive phone and tablet layouts.
- All artwork is procedurally generated SVG and all audio is synthesized with Web Audio.

Open `index.html` or serve this directory with any static file server:

```bash
python3 -m http.server 3002
```

Tests for the headless rules engine (288 full simulations) run with:

```bash
node tests/sim.cjs
```
